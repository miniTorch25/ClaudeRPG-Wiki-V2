## Hybrids · ธาตุผสม (6)

**EN:** Two different elements of the same tier on a set form a hybrid (count = min x 2). Hybrid Mixing can be turned off in Status > Chorus.

**TH:** ธาตุ 2 ชนิดในระดับเดียวกันรวมเป็นธาตุผสม (จำนวน = ค่าน้อย x 2) ปิด Hybrid Mixing ได้ที่ Status > Chorus

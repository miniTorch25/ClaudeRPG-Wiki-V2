# Glossary · อภิธานศัพท์


**EN:** Key terms used across the wiki.

**TH:** คำศัพท์สำคัญที่ใช้ทั้งวิกิ

| Term | Meaning / ความหมาย |
|---|---|
| **Ascension** | World difficulty level pressed by one player; scales mobs and unlocks Mob Evolution. · ระดับความยากของโลก |
| **Augment** | Random bonus stats on weapons, tools and armor. · ค่าโบนัสสุ่มบนอุปกรณ์ |
| **Awaken / Melodious / Genesis** | Top Chorus tiers made by Fusion. · ระดับสูงสุดของ Chorus จากการหลอม |
| **Chorus** | Elemental armor set system. · ระบบเกราะธาตุ |
| **Echo / Resonance / Transcend** | The three rollable Chorus tiers. · 3 ระดับ Chorus ที่สุ่มได้ |
| **Engraver** | Tool that carves Uncarved Gems/Runes and drills Gem sockets. · เครื่องมือแกะสลัก |
| **Evolve** | A mob that evolved into a stronger tier (Tough, Elite, Sculk…). · มอนสเตอร์วิวัฒนาการ |
| **Gem Potency** | Mastery bonus (up to +20%) that boosts Gem power numbers. · โบนัสเพิ่มพลัง Gem |
| **Hybrid** | Two elements of one Chorus tier forming a combined set. · ธาตุผสม |
| **Requirement** | Minimum stats an item needs. · ค่าสเตตัสขั้นต่ำของไอเทม |
| **Limit Break** | Prestige bonus raising every stat cap. · โบนัสเพิ่มเพดานสเตตัสจาก Prestige |
| **Mastery** | 11 skill lines that level through play. · สายทักษะ 11 สาย |
| **Perk** | One permanent bonus picked per Prestige. · พลังพิเศษที่เลือกทุก Prestige |
| **Prestige** | Reset Level/XP/stats for higher caps and perks. · รีเซ็ตเพื่อเพดานที่สูงขึ้นและ Perk |
| **Resonant Ink** | Currency for Chorus and Rune actions. · วัสดุจ่ายค่า Chorus และ Rune |
| **Rider** | Bonus effect from Chorus Synergy on hits. · เอฟเฟกต์เสริมจาก Synergy |
| **Synergy** | Gems/Runes growing stronger with matching Chorus elements. · พลังเสริมเมื่อธาตุ Chorus ตรงกัน |
| **Toast** | Advancement-style pop-up notification card. · การ์ดแจ้งเตือน |
| **Vein** | Augment stat that breaks connected blocks. · ขุดบล็อกที่ติดกันพร้อมกัน |

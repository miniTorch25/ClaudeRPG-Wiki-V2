## Categories · หมวดหมู่

**EN:** Every item belongs to a group and a kind. The kind decides which Runes it can hold and which Augment pool it uses.

**TH:** ไอเทมทุกชิ้นอยู่ในกลุ่มและชนิดหนึ่ง ชนิดกำหนดว่าใส่รูนอะไรได้และใช้พูล Augment ไหน

| Group / กลุ่ม | Kinds / ชนิด |
|---|---|
| **Weapon** · อาวุธ | Sword (ดาบ), Bow (ธนู), Spear (หอก), Trident (ตรีศูล), Mace (กระบอง), Magic (เวท) |
| **Tool** · เครื่องมือ | Pickaxe (พิกแอ็กซ์), Axe (ขวาน), Shovel (พลั่ว), Hoe (จอบ), Shears (กรรไกร) |
| **Armor** · เกราะ | Helmet (หมวก), Chestplate (เกราะ), Leggings (กางเกง), Boots (รองเท้า), Shield (โล่) |
| **Consumable** · ไอเทมใช้งาน | Food (อาหาร), Drink (เครื่องดื่ม), Ammo (กระสุน), Gem (มณี), Rune (รูน) |

## Rules · กฎ
- **Rune:** only weapons and tools (not Shears) can hold a Rune. · รูนใส่ได้เฉพาะอาวุธและเครื่องมือ (ไม่รวมกรรไกร)
- **Gem:** armor only. · Gem ใส่ได้เฉพาะเกราะ
- **Augment:** weapons, tools and armor. Shears roll Vein only. · Augment ใช้ได้กับอาวุธ เครื่องมือ เกราะ กรรไกรได้ Vein อย่างเดียว
- Weapon mapping: Sword = swords, Spear = spears, Bow = bow & crossbow, Trident = trident, Mace = mace, Magic = reserved for future magic weapons. · ตรีศูลคือ trident
- Wooden / leather / golden-tier items are tracked so they can be augmented and socketed. · ไอเทมไม้ หนัง ทอง ก็ Augment และใส่ช่องได้

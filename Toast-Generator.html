Toast Generator

Configure a Toast notification, preview it using the add-on's original frame and achievement-icon textures, then copy the command for Minecraft Bedrock.

Source-verified format · ClaudeRPG v1.39.0 รูปแบบคำสั่งตรวจสอบจากซอร์สแล้ว · ClaudeRPG v1.39.0

This tool uses the command implemented in the add-on: /scriptevent toast:send target | frame | icon | header | body | sound. The preview is a browser approximation of the in-game 160×40 UI card; exact rendering still depends on Minecraft's UI renderer.

เครื่องมือนี้ใช้คำสั่งที่พบในแอดออนจริง: /scriptevent toast:send target | frame | icon | header | body | sound ตัวอย่างบนเว็บเป็นการจำลองการ์ด UI ขนาด 160×40 ในเกม การแสดงผลจริงยังขึ้นกับตัวเรนเดอร์ UI ของ Minecraft

Usage and limitsข้อควรรู้ก่อนใช้
  • Sending to yourself with @s is free. A normal player sending to another player pays 10 Common Gems and has a 3-second cooldown.
  • Admin, command-block, and console sends are free; only privileged sources may use @a, @p, or @r.
  • The header accepts English ASCII characters only and is limited to 28 characters. The body can use Minecraft colour codes; the card displays about 22 visible characters before truncation.
  • The target player must be online. If their Toast setting is off, the message falls back to chat.
  • ส่งให้ตัวเองด้วย @s ฟรี ผู้เล่นทั่วไปที่ส่งให้คนอื่นเสีย Common Gem 10 ชิ้น และมีคูลดาวน์ 3 วินาที
  • คำสั่งจาก Admin, Command Block และ Console ฟรี เฉพาะแหล่งที่มีสิทธิ์เท่านั้นที่ใช้ @a, @p หรือ @r ได้
  • หัวข้อรับเฉพาะอักขระ ASCII ภาษาอังกฤษ ไม่เกิน 28 ตัว ข้อความรองรับรหัสสี Minecraft และการ์ดแสดงผลได้ประมาณ 22 ตัวก่อนถูกตัด
  • ผู้รับต้องออนไลน์ หากปิด Toast ไว้ ข้อความจะถูกส่งผ่านแชตแทน
